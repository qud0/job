# Домашний винный погреб

Веб-приложение для учёта вин в личной коллекции. Позволяет вести каталог наименований, фиксировать закупки бутылок, отслеживать стоимость и места хранения.

## Возможности

- Дашборд с ключевыми показателями коллекции.
- Каталог вин с фильтрами по основным характеристикам.
- Карточка вина с историей закупок и заметками.
- Добавление и удаление бутылок, подсчёт остатка и стоимости.

## Стек

- Python 3.11+
- Flask 3
- SQLite (по умолчанию)

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run --debug
```

При первом запуске база данных создаётся автоматически в директории `instance/`.

## Структура проекта

```
.
├── app.py              # точки входа и маршруты
├── models.py           # ORM-модели SQLAlchemy
├── templates/          # HTML-шаблоны (Jinja2)
├── static/             # стили
└── requirements.txt    # зависимости
```

## Переменные окружения

- `SECRET_KEY` — секретный ключ Flask (по умолчанию `dev`).
- `DATABASE_URL` — строка подключения SQLAlchemy. Например, `sqlite:///winecellar.db` или `postgresql://user:pass@host/db`.
